# 加密网页库 · Cloudflare 版

- 网址：https://my-web-library.lunette.workers.dev
- 外壳（2026-09-29 起）：Sidereal。解锁页是粒子变形，书库是水天相接，进入作品时穿过星球的大气层。源码在 `work/next-zone/src`，由 `work/next-zone/build.mjs` 打包，里面包括 three.js。
- 加密内容：取自 Firebase 正式包「加密网页新密码本机版」的 vault，逐字节相同，没有重新加密。
- 生成：`node work/cloudflare/make-package.mjs`。它会先让正式包过一遍自己的校验，再打包外壳、组装本目录、写入发布校验清单。
- 发布：在本目录运行 `./发布.sh`。wrangler 会先跑 deployment-guard.cjs，文件和清单对不上就中止。
- public 里比正式包多出来的：`assets/`（打包后的主程序和银河全景图，缓存一年，文件名带哈希）、`_headers`（安全头）。没有 gate.js。
- 银河全景：ESO/S. Brunier（eso0932a），页面右下角有署名。
- 不要加 `main` 脚本，守卫会拒绝：这个站只放静态文件。
